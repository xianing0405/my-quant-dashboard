# 资料目录（raw_docs/）

这是内部知识库的**正式入库目录**：把研究材料（研报、会议纪要、对话记录等）放入本目录，
再通过页面「资料管理 → 扫描资料目录」或命令 `python -m core.knowledge.cli scan` 触发解析与索引。

> 本目录内的**正文文件一律被 Git 忽略**（`.gitignore` 已配置），不会随代码提交到公开仓库。
> 本说明文件与目录骨架可以提交。请勿把内部材料、密钥或含原文的索引提交到 Git。

## 支持的文件格式

| 格式 | 说明 |
| --- | --- |
| `.pdf` | 有文本层的 PDF（自动识别页码）；扫描件无文本层会标记「需要 OCR」，不显示入库成功 |
| `.docx` | Word 文档（段落 + 表格，表格转文本并提示核对） |
| `.md` / `.markdown` | Markdown |
| `.txt` | 纯文本 |
| `.rtf` | 富文本（自动解码） |
| `.json` | 对话记录（见下方 JSON 约定） |

**暂不支持**（后续能力，不会被伪装成已支持）：Excel / PPT / 图片 / 音频。

## 对话记录导入格式

### TXT 约定（自动识别）

每行一条消息：`[时间] 发言人（角色）：内容`，时间与角色可省略。

```
# 团队会议 2026-09-16
[2026-09-16 14:30] 张三（提问）：碳化硅现在怎么看？
[2026-09-16 14:32] 李四（回答）：若美联储降息则重点关注。
[2026-09-16 14:35] 张三（观点）：但需警惕产能过剩。
```

角色可为：`提问 / 回答 / 观点`（可省略）。省略时间时，位置用「消息 N」标注，不编造时间。

### JSON 约定

```json
{
  "format": "dialogue",
  "title": "团队会议 2026-09-16",
  "messages": [
    {"speaker": "张三", "role": "question", "time": "2026-09-16T14:30:00", "text": "碳化硅现在怎么看？"},
    {"speaker": "李四", "role": "answer", "time": "2026-09-16T14:32:00", "text": "若美联储降息则重点关注。"}
  ]
}
```

## 其他说明

- 只递归顶层、不递归子目录；文件名即默认标题，可人工在页面上传时修改元数据。
- 发布日期与上传时间分开保存；发布日期未知时保留为空（在页面标注「日期未知」）。
- 原始文件始终保留，系统只保存解析片段，不保存 AI 摘要作为唯一来源。
- 重复内容（按文件哈希）不重复入库；同标题新内容自动作为新版本保留版本关系。
- 删除文档会同步清理其可检索片段与派生的观点记录，防止删除后仍被召回。
